# 六级喵 V2.0

面向 iPhone Safari 的六级学习工具。在现有 chinese-pomodoro 上增量升级，保留番茄钟、112个学习词条、间隔复习、阅读、心境和泰迪养成；新增学习首页、听力、写作翻译与完整备份。无需登录、后端、付费 API 或第三方运行依赖。

**当前状态：本地开发/自动化测试完成，等待用户验收；本次未推送或部署线上。**

## 每天怎么用

首页展示真实学习进度；设置每日新词、复习、阅读、听力数量及考试日期。主导航为首页、背单词、训练、宠物、设置；番茄钟、阅读、听力、写作翻译在“训练”中，也保留 `#focus` 等原入口。“继续上次学习”恢复学习模块；单词轮次、阅读作答、听力练习及草稿分别保存自己的进度。

- **单词**：固定轮次的 Fisher–Yates 乱序、顺序、薄弱词排序；认识/模糊/不认识；到期复习和错词练习；发音、例句、搭配、联想、自定义词和双向小测。认识后1/3/7/14/30/60天复习，模糊30分钟，不认识10分钟。额外练习不重写尚未到期的间隔、不刷奖励。
- **阅读**：仔细阅读计时、自动保存答案、交卷解析、原文依据和同义替换、干扰项分析、错因、收藏文章/题目、按错因筛选与单题复练。离开阅读或进入后台暂停阅读计时。生词先补齐释义再进学习队列。
- **听力**：本地MP3/WAV/M4A/OGG配对、原生播放控件、前后5秒、倍速、AB循环、逐句精听、隐藏原文、听写核对、错句筛选、表达收藏、手动加入生词、前台有效播放时长与完成记录。恢复上次材料、句子、播放位置及听写输入；不会自动播放。听写比较忽略标点/大小写，文本相似度不代表考试正确率。
- **写作翻译**：两道原创示例、JSON题目导入、限时练习、字数统计、自动草稿、每题10个手动版本、恢复前保留当前版本、原创参考和思路模板、表达收藏、自查清单、当前草稿导出。离开或进后台暂停计时，不伪装AI评分。
- **心境与伙伴**：自愿签到、精力自评、非医疗模式建议/手动切换、可暂停呼吸、2分钟学习启动、本机合成白噪音。默认新用户是小猫小桔；老用户的泰迪小满、等级、金币和物品保留，可在小屋切换外观。心境不影响奖惩，断签不扣状态。
- **奖励**：保留专注25经验/10金币、每日30新词20金币/2食物、到期正确复习奖励；新增阅读/听力每日每份10经验/5金币，写作每日每题8经验/3金币，正确听写每句每天2经验。相同内容改ID重复导入不会重复奖励；心境/放松不提供可刷奖励。

内置112词与1篇5题阅读沿用旧版，新增2道写作翻译题、1份无录音的听力原文示例，均作为学习演示，不声称为官方词表/真题。没有擅自抓取或打包外部大词库，没有预装受版权限制的听力。

## 导入自己的资料

词库和仔细阅读使用“设置 → 词库/阅读导入”；听力原文与本地音频在听力训练室，写作翻译题在写作页。完整格式和使用范围见 [IMPORT-FORMATS.md](IMPORT-FORMATS.md)。

| 内容 | 支持格式 | 模板 |
| --- | --- | --- |
| 单词 | CSV、JSON、JSONL（含JSONL.txt） | materials-word-template.csv / .json |
| 仔细阅读单选 | JSON，需完整解析/依据句 | materials-reading-template.json / reading-template.json |
| 听力原文时间轴 | JSON；音频另选本地文件 | listening-template.json |
| 写作/翻译 | JSON | writing-template.json |

词库先预览、修改、补全来源/许可、去重，再勾选核对并确认。重复或缺字段词条会逐项跳过，**有效词条仍能确认导入**；JSONL坏行和CSV列数不齐按记录保留错误，不阻塞其余有效项。CSV引号未闭合、JSON整体语法损坏等无法可靠解析的文件会停止并提示修复。导入不猜测音标、释义、例句或题目答案。

听力和写作导入逐项校验，展示有效/跳过数量及原因；确认后添加。相同ID、相同内容、已归档记录的ID不会覆盖。移除材料保留学习历史；想导入不同内容须使用新的ID。

## 数据安全和隐私

- 原学习 key `yike-study-v2`、原资料库 `yike-materials-v1` 均不改名；旧 `yike-pomodoro-v1` 迁移仍有效。原主数据 `version:2` 保持兼容，V2新增内容位于 `platform` 字段，缺失时补默认值，不重算旧词进度。
- 第一次写入V2前保留一次 `yike-study-v2-before-v2.0` 原始副本。存储不足时停止写入并提示，不先清空旧记录。已有v1.1/v1.2恢复副本继续保留。
- **资料导入与整站恢复分开**。正常资料导入仅追加，进度不覆盖。整站恢复需格式/音频SHA-256校验、预览、明确确认；确认后才替换主学习数据，先保存 `-before-import` 副本。现有资料、音频只追加不清库，重复跳过；心境默认保留，可选按日期合并。旧版备份没有V2字段时保留本机新增训练数据。
- **导出整站JSON包含音频**（base64）、资料、草稿、单词和心境。文本、资料或音频库读失败时不会称为“完整备份”。另有明确标注“不含资料和音频”的学习文本应急导出；其中未保存输入也附带，可恢复。恢复前副本导出仅包含主学习文本，原IDB资料和音频仍留本机。
- 音频在独立IndexedDB `liujimiao-media-v2` 中，单文件≤25MiB，总量≤60MiB/200个，绝不塞入localStorage。完整备份≤100MiB，包含音频编码开销。资料中心单文件≤10MiB，文本库≤5000条/6MiB；听力/写作JSON≤5MiB，最多200份听力/500题写作翻译。
- 不登录、不云同步、不将资料或心境发送给第三方。原文音频仅选择本地Blob；白噪音本机合成。语音发音由系统SpeechSynthesis提供，语音可用性/是否离线由浏览器和系统决定。
- 心境可单独清除，相关本机恢复副本同步清理心境，不删除学习数据或已下载文件。完整备份包含私人日记，务必自己保管。
- 同一GitHub Pages站点更新文件通常保留Safari现有数据。**不要清除网站数据，不要删除数据库，不要使用隐私浏览作为长期存储，不要同时开着新旧版本反复操作。** 不同浏览器/设备的数据独立；浏览器也可能回收存储，应每周导出整站备份。
- 跨不同存储系统无法做到单一事务：恢复先幂等追加资料/音频，再提交主状态。若中途失败，旧主记录保留，可能有已追加的资料；保管备份后重试，应用会跳过重复项，不会删除旧资料。

## iPhone Safari 验收

见 [IPHONE-ACCEPTANCE.md](IPHONE-ACCEPTANCE.md)。自动化使用Chromium移动尺寸，不能替代真实iPhone的语音、音频解码、文件选择/下载、存储回收和触控检查。Safari需主动点击播放；进入后台主动暂停训练，不保证锁屏循环或后台提醒。长音频建议分段，备份期间留在页面。

## 本地预览和开发检查

在项目目录运行 `python3 -m http.server 8082`，电脑浏览器打开 `http://localhost:8082/`。手机实测需要手机可访问的HTTPS测试地址；手机无法访问本开发环境的localhost。不要把HTML直接在“文件”App的预览当作完整Safari网站运行。

运行规则检查：

```sh
node check.cjs
node check-v1.1.cjs
node check-v1.2.cjs
node check-garden.cjs
node check-v2.cjs
```

本地服务器运行时，安装开发用Python Playwright/Chromium后运行 `browser-v1.2.py`、`browser-garden.py`、`browser-v2.py`、`browser-v2-edge.py`。测试工具不属于网站运行依赖。测试结果见 [TEST-REPORT-V2.md](TEST-REPORT-V2.md)。`browser-check.py`、`browser-v1.1.py`为旧版界面历史验收，保留参考。
