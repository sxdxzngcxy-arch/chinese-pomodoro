## 这次不只是导入器

打开新版本即可使用：**1675个去重词、7篇原创阅读/23题、6段有声精听、5道作文和5道翻译**。内置资料已通过相对路径接入，无需一个文件一个文件导入。

- 词汇补充释义由本项目编写，是常见备考词补充集，不是官方完整词表；部分词缺音标或例句时留空并提示。原词库的丰富词卡继续保留。
- 全词库搜索、状态筛选、20词分页和收藏；学习仍是固定轮次、认识/模糊/不认识、间隔重复和错词复习。原个人/导入词优先，稳定词ID保留。
- 新增看中文拼写/听音拼写，10词一轮，优先已学词，轮次/输入可恢复；与原SRS和奖励分开，重复点击不刷分或金币。
- 阅读按原文依据、同义替换和干扰方式解释；新增场景为原创模拟，不引用虚构的真实科研结论。原错因分类/收藏/重练/生词联动保持。
- 精听有实际MP3与按合成时长生成的逐句时间轴，支持播放/倍速/AB/隐藏原文/听写。录音是eSpeak NG本地合成，不是真人或官方考试录音。用户自己的音频仍可优先配对并保存在IndexedDB。
- 作文/翻译提供原创题干、参考文本、自查、计时、自动草稿与版本；不伪装AI自动评分。
- 首页显示实际进度和资料数量、继续上次学习、可自定考试日期/目标。浅深色、大字、减少动画保留。心境自愿，不诊断疾病，不扣宠物状态。

**外部词典不随公开网站ZIP打包**：仓库标注BSD-3-Clause，但上游第三方公开再分发授权未核实。网站只在主动选择后读取并本机处理，不上传学习记录。另有单个JSON的本机备用包，保留原许可证，不能跟网站代码一起公开上传。来源与限制详见 [V4.4-SOURCES.md](V4.4-SOURCES.md)。

Codex无法跨设备直接写入你iPhone Safari的localStorage/IndexedDB，所以外部词库最后仍需在手机上确认。网站内置原创资料已经接入，不需要这一步。

## 导入、存储与隐私

- V2.1批量CSV/JSON/JSONL词库和阅读JSON继续可用：追加选择、统一预览、跨文件去重、逐文件进度、取消、问题筛选/编辑和报告。单个坏文件/坏行不阻塞其他有效项。
- 同一预览最多50文件/20MiB/5000项，单文件≤10MiB；原资料库≤5000条/6MiB。听力原文/写作JSON在各自页面导入，自选音频单文件≤25MiB、总量≤60MiB，音频不塞入localStorage。
- 文件只在本机处理；手动确认后才追加，不覆盖旧学习进度。未确认的预览在内存，刷新会丢失，原文件可以重选。ZIP先在“文件”App解压。
- 资料导入和整站恢复分开，误选整站备份会提示正确入口。完整学习JSON包含主状态、资料与自选音频；内置静态词库/题目/MP3随网站代码保存，不在每次学习备份重复编码。
- 继续使用原 `yike-study-v2`、`yike-materials-v1` 和 `liujimiao-media-v2`。产品版本4.4不把主数据格式版本改成4.4：主数据仍是 `version:2`，保持兼容。
- 首次升级前保存 `-before-v4.4` 原始副本；旧猫形象迁移到贝贝，经验/等级/金币/装饰/任务/复习记录保持。升级后自主切换外观也会保留。
- 整站恢复先校验/预览/确认、保留 `-before-import` 副本；心境默认保留，可按日期合并。清除心境也会清理各恢复副本中的心境，已下载文件需自行保管。
- 存储不足时停止写入并提示，原数据不自动清除；如果事务成功但列表刷新失败，会准确提示已保存并支持重连。
- 没有登录或云同步，数据不能自动跨设备共享。不要清除Safari网站数据，不用隐私模式长期学习，建议每周导出备份。系统语音、可用容量和后台策略由设备决定，不保证锁屏播放/循环/提醒。

## 项目结构

沿用原纯HTML/CSS/JavaScript模块：`core.js`/`learning-core.js`/`platform-core.js` 是规则与兼容层，原页面控制器和IndexedDB保持。V4.4新增：

- `v44-vocabulary.js`：原创补充词，兼容原个人词ID。
- `v44-content.js`、`beibei-listening-01.mp3`至`06.mp3`：原创阅读/写作/翻译/有声精听。

- `spelling-core.js`、`v44-tools.js`、`v44.css`：可恢复拼写、资料概览、全词库浏览。
- `v44-*-template.csv/json`：可导出的资料模板；内置同款已经可用，不必重复导入。
