# 六级喵 · 学习与心境伙伴
本次版本为 **V1.2 智能背单词**。在原项目上补齐可恢复的学习轮次、独立复习目标、结果与历史，以及统一词库导入流程。交付、数据结构、测试和 iPhone 验收见 [REVIEW-V1.2.md](REVIEW-V1.2.md)。现有番茄钟、阅读、心境花园和泰迪小满保留。

心境入口位于页头及专注页，底部原5项导航保持。自愿选择感受/精力，可跳过；三种模式可手动改；1–3分钟静音呼吸可暂停、停止或自然呼吸；日记选填，支持最近7天查看、修改、删除、单独导出/清除。新增功能不判断疾病、不读取日记进行推断，不向第三方发送心境。

同一个本地 key 新增 `garden` 字段，旧记录缺字段时补空值；完整备份包含心境与日记。**导入时本机心境默认保留**，若勾选心境合并，只补缺失日期，相同日期保留本机。学习部分仍按已有流程预览/确认后恢复，并保存本机恢复副本。

模式切换仅改变建议；“准备本次专注”才显式设置一次性时长，已有进度需再确认。呼吸每5秒保存检查点，刷新恢复并暂停，不补算后台完成、不发奖励；感受和断签不扣成长。仅点击“保存记录”才留下签到，未保存的表单不作自动日记。

在现有 chinese-pomodoro 项目上持续升级，沿用 HTML、CSS、JavaScript 和 GitHub Pages。没有新建项目、没有删除番茄钟/宠物，也没有调用付费 API。本版产品版本是 **V1.2**，原存储格式仍沿用 `version: 2` 以兼容已部署版本，两者含义不同。

## 本版真实可用的功能

### 智能背词

- 保留原 112 个六级常用进阶词，未增加未经核实的大词表；原有音标、词性、释义、双语例句、翻卡、三档自评和 SRS 都在。
- 顺序学习、随机乱序、薄弱词优先。使用 Fisher–Yates，在点击“开始本轮学习”时仅抽样洗牌一次，保存本轮词 ID 与当前位置；作答、导入词条或刷新不会重新抽样。
- 随机模式从所有未学词随机取每日额度，并混排到期词；薄弱优先先排到期错词与低正确率词，再排新词。顺序模式保持原词库顺序。
- 同一轮不会重复抽卡。到期复习才改变间隔；“只练错词”优先到期词，其余可额外练习，不改变原进度或奖励。额外练习会轮换未练过的错词，避免始终卡在词库前几项。
- 每日新词默认 30，可设 1–200；每日复习默认 30，可设 0–200，独立计量、不占新词额度。升级后按不同的复习词计入目标，旧版当天复习次数保留为基线。目标和排序改变从下一轮生效；本轮保持不变。
- 显示未学、认识、模糊、不认识、已掌握。“已掌握”指至少连续推进至 7 天复习阶段的本地自评标签，不代表考试保证；答错后可回退。
- 保留英译中 / 中译英四选一小测，选项也使用 Fisher–Yates。每词每方向每天只计分一次。
- 英式 / 美式发音选择，使用浏览器 SpeechSynthesis，缺少对应音色时回退至其他英语语音；iPhone 需主动点击发音。
- 收藏可在“我的词库 → 管理 / 收藏”查看与取消。

### 个人词库、导入和联想

- 自定义添加英文、释义、音标、词性、例句、翻译、搭配和辅助联想；英文与释义必填。已保存词的英文是稳定 id，不可直接改名，其他内容可编辑；删除需要再确认一次。
- 词卡页与资料中心共用 JSON / CSV 导入：预览、编辑、错误提示、去重、来源及许可核对。文件不上传；确认后写入 IndexedDB，自动接入背词。重复项只跳过，不覆盖内置、旧个人词或学习进度。缺少释义、来源或许可的条目须补齐，或取消勾选后再导入其他有效条目。
- CSV 支持中英文常用表头、BOM、引号内逗号、双引号转义、字段内换行。资料中心单文件最多 10MB，最多 5000 项 / 6MB 文本；旧个人词仍保存在原处，不自动搬移。Excel、PDF、Word、音频导入尚未实现。
- 删除个人词只移除词条，保留历史进度与奖励去重记录；重新加入同一英文不会把旧进度当成新词刷奖励。
- 提供 6 条人工整理的联想示例，其中 3 条词源有 Etymonline 参考链接。界面明确分开“词源知识”和“辅助记忆联想”。未整理词源时直接说明，不编造拆分或谐音词源。
- 个人输入的联想只标记为辅助记忆；不自动声称来自词源。常见搭配、易混词和主动回忆只在有整理内容时显示。

### 基础仔细阅读

- 内置 **1 篇原创模拟题 / 5 道单选题**，清楚标注来源。不是历年真题，不换算官方 CET-6 分数。
- 围绕选择偏差、因果推断、选项范围、同义替换、主旨与作者态度设计题目，帮助训练“看懂文章但选项容易选错”。
- 开始、暂停/继续阅读计时；选项实时保存；刷新继续草稿。阅读计时与番茄钟独立，切换页面不会自动暂停。
- 全部作答后才交卷；交卷后显示练习正确率、正确答案、依据句、同义替换、每个干扰项的解释。文章中自动高亮依据句，点击解析中的依据可定位原段。
- 标记错因：词汇、定位、推断、主旨、同义替换、时间不足；错因分布按最近一次仍答错的题统计。
- 题目收藏、全文再练、仅重练错题。重练答对后从当前错题集合移出，保留总作答次数和历史正确次数。未完成草稿不会被“重练”直接覆盖。
- 点文章里的英文词 → 加入生词本。已在本地词库中的词显示释义，不重复添加；新词先存成“待完善”，保留原段落上下文。补齐释义后才纳入背词，避免学习空白或猜测内容。
- 导入自己的阅读 JSON，严格检查来源、题型、选项、答案、解析与依据句是否出现在原段落。重复 id 跳过、不覆盖已有题目或记录。单文件 2MB，最多 100 篇个人材料。
- 本版仅实现 `reading-careful` + `single-choice`。`audioUrl` 保存为预留元数据，没有伪装成可用的听力播放器。

### 保留的原有功能

- 番茄钟默认 25 / 5 分钟；开始、暂停、继续、重置、模式切换、自定义时间、任务添加/勾选/删除、今日次数和分钟。
- Q版泰迪“小满”：眨眼、呼吸、摸头/玩耍/睡觉、庆祝/升级、经验/金币/食物、小屋装饰与徽章；外观注册表仍支持扩展。
- 完成专注 25 经验 + 10 金币；每天首次学 30 个新词获 20 金币 + 2 食物；正确到期复习每词每天 2 经验一次，奖励账本防重复结算。
- V1.1 阅读暂不额外发奖，不会通过反复交卷无限增加金币。
- 浅色/深色/跟随系统、减少动画、统计、连续学习、近七天趋势、完整学习数据 JSON 备份。

## 词库格式

JSON 可为数组或 `{"words": [...]}`，词条必填 `word`、`meaning`。来源与版权/许可可在根对象填写 `source`，也可在预览中批量补充。未知年份允许留空，不能把自备材料标成官方真题。

```json
{
  "source": {"kind":"user-provided","label":"个人学习笔记","rights":"本人整理，供个人学习使用"},
  "words": [
    {
      "word": "resilient",
      "ipa": "/rɪˈzɪliənt/",
      "pos": "adj.",
      "meaning": "有韧性的；能恢复的",
      "example": "A resilient learner adjusts the plan after a setback.",
      "translation": "有韧性的学习者会在受挫后调整计划。",
      "collocations": "a resilient learner",
      "association": "辅助联想：像弹簧一样恢复，不是词源。"
    }
  ]
}
```

CSV 使用同名英文字段作表头，也支持“英文、释义、音标、词性、例句、来源、许可”等中文表头。可直接参考 [materials-word-template.csv](materials-word-template.csv) 和 [materials-word-template.json](materials-word-template.json)；旧 [word-template.csv](word-template.csv) 可用，但要在预览补充许可。不要将整份学习备份当成词库导入，恢复记录应使用“统计 → 数据备份”。

## 阅读题库结构

完整可导入样例见 [reading-template.json](reading-template.json)。资源用相对路径或 HTTPS，来源必须真实、具备使用权。以下为结构摘要，不是可直接导入的完整题目：

```text
{
  schema: 1,
  articles: [{
    id: 稳定且唯一的文章ID,
    type: "reading-careful",
    title: 标题,
    source: {
      kind: "original" | "user-provided" | "licensed" | "public-domain",
      label: 来源名称,
      rights: 授权或使用范围说明
    },
    year: 年份或 null,
    audioUrl: HTTPS地址、相对路径或空字符串（本版仅保存），
    paragraphs: [{id: "P1", text: 英文段落}],
    questions: [{
      id: "Q1", type: "single-choice", stem: 题干,
      options: [{id: "A", text: 选项}, ...],
      answer: 正确选项ID,
      explanation: {
        summary: 答案解析,
        evidence: [{paragraphId: "P1", quote: 原文逐字依据句}],
        paraphrase: 同义替换说明,
        distractors: {错误选项ID: 干扰项解释, ...}
      }
    }]
  }]
}
```

不要把原创模拟题或未经核实的材料标为“历年真题”。长篇匹配、选词填空、听力、写作和翻译会在后续版本扩充 schema 与界面，当前导入流程会拒绝未支持题型。

## 发布后在 iPhone 的验收场景

- 在同一个 Safari、同一个原网址重新加载，检查原任务、专注记录和小满金币仍在；不要清除网站数据。
- 背单词选择随机，记下当前词后刷新，应保留；评价后不会立刻重复。切换薄弱优先，已到期错词会优先出现。
- 添加一个个人词；用示例 CSV 预览导入，重复导入应跳过，不覆盖已编辑释义。
- 阅读点击开始，选一题后刷新，答案仍在；交卷可看依据和干扰项，标记错因，再重练错题。
- 从阅读点一个新词，存入待完善生词，补充释义后在个人词库可查看。
- 统计页导出再选择这份 JSON，只应在确认替换后恢复；切换深色和减少动画，检查阅读和宠物页面。

这些是测试场景，部署与验收时可在会话中一次只完成一个。V1.2 的当前词卡需先点“开始本轮学习”，本轮结果与最近100轮记录可查看。
