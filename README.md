# 一刻专注 v2 · 番茄钟 + 六级词汇 + Q版泰迪小狗

在原有 chinese-pomodoro 项目上升级，保留番茄钟、任务清单、专注次数和本地保存。纯 HTML / CSS / JavaScript，无构建、无运行时依赖、无后端，适合 GitHub Pages。

## 开始使用

```sh
cd /workspace/chinese-pomodoro
python3 -m http.server 8080 --bind 0.0.0.0
```

电脑访问 `http://localhost:8080`。手机与自己的电脑在同一 Wi-Fi 时，Safari 可访问 `http://电脑局域网IP:8080`；远程 Codex 工作区的 localhost 不能直接在手机打开，请使用端口转发或 GitHub Pages。直接打开 HTML 仅适合看界面，正式使用请走 HTTP/HTTPS。

底部有四个页面，支持 `#focus`、`#words`、`#pet`、`#stats` 地址定位。

## 功能与规则

### 专注

- 默认专注 25 分钟、休息 5 分钟；支持开始、暂停、继续、重置、切换模式。
- “调整时间”可设专注 1–180 分钟、休息 1–60 分钟；保存会重置当前一轮。
- 保留任务添加、勾选、删除、清除已完成，以及按本地日期计算的今日专注记录。
- 完成一轮专注：25 经验 + 10 金币，小狗庆祝；完成后切换为休息，手动开始下一段。
- 实际时长独立记录，自定义 20 分钟完成后就记 20 分钟；旧记录按原来的每次 25 分钟迁移。
- 按截止时间计算剩余时间；锁屏/后台可能挂起页面，返回时校正并结算。跨午夜归入实际完成日。
- 未完成的重置或切换模式不发奖励。休息不发奖励。

### 六级背单词

- 内置 **112 个六级常用进阶词**，每词有英文、英式常见音标、词性、中文释义和原创双语例句；不是官方频率排名或完整六级词表。
- 默认每天 30 个新词，支持 1–200 的目标设置。到期复习优先，目标只限制新词，不限制复习。
- 点击卡片查看释义后，选择“认识 / 模糊 / 不认识”。第一次评价就算学习了 1 个新词；自评“认识”计入正确次数。
- 认识后按 **1、3、7、14、30、60 天**安排复习；模糊 30 分钟后、不认识 10 分钟后再出现。模糊/不认识均纳入错词本。
- 错词本可查看全部错词及下次到期时间，上方卡片仅显示已到期的错词。到期词卡选“认识”后移出错词本。
- 英译中 / 中译英采用四选一，仅测已学词，每词每方向每天只计分一次。小测答错加入错词本，并将复习时间提前到不晚于 10 分钟后；小测不发经验，也不延长间隔。
- 每天首次完成 **30 个新词**（与目标设置独立）获得 20 金币 + 2 食物；目标低于 30 时无此奖励，但已学内容照常保存。
- 正确复习已到期的旧词获得 2 经验，每词每天限一次；首次学习不发这项经验。日奖励和已评分结果不会因刷新重领。
- 学完内置新词后继续复习，不会循环冒充新词；界面会提示下次到期时间。可以扩展词库。
- 今日学习量分为新词数和词卡复习次数；正确率为词卡自评“认识”和小测答对占全部评价/作答的比例，不是考试预测分数。
- 连续天数按本地日期有无词卡评价或小测作答计算；今天尚未学时，允许显示截至昨天的连续记录；中断不扣宠物状态。
- 点击发音使用 SpeechSynthesis API，优先英式英语语音，回退至其他英语语音；不支持时保留音标并提示。

### 小满的宠物小屋

- 初始宠物为本地 SVG Q版泰迪小狗“小满”，卷毛、圆耳、奶油肚皮；使用 CSS 制作眨眼、呼吸、摇尾、摸头蹭蹭/爱心、玩耍、睡觉/唤醒、学习完成庆祝和升级光圈。直接点小狗也可以摸头。减少动画时保留静态表情和文字反馈。
- 经验每满 100 升一级，展示心情、饱食度、亲密度、金币和食物。
- 摸头（1 分钟冷却）、玩耍（10 分钟冷却）、喂食（消耗食物，吃饱后不再消耗）、睡觉/唤醒。
- 互动只增加有限状态，不发金币/经验。玩耍轻微消耗饱食度，最低保持 20；离线无衰减，不死亡、不催促。
- 商店可购买绿植、地毯、台灯，永久放在房间；同一物品不能重复购买。
- 成就：初次专注、30 词、100 词、亲密度 20、累计 200 经验；满足条件自动点亮，不额外发奖。

### 统计、显示与备份

- 今日新词、复习、正确率、连续天数、近七天学习柱状图、累计单词和专注分钟。
- 跟随系统/浅色/深色；减少动画开关，同时尊重设备的减少动态效果设置。
- 统计页可导出完整 JSON：设置、任务、计时、单词进度、宠物、学习记录和去重账本。
- 导入限制 10MB，进行结构/数值/版本校验并预览；**点击“确认替换”后才写入**，不与现有数据合并。建议先导出当前数据。
- 导入前的数据另存于 `yike-study-v2-before-import`，以便技术恢复；常规恢复方式是导入已下载的备份。备份中的运行计时会被暂停，不在导入时自动结算奖励。
- iPhone：导出后将下载文件保存在“文件”App；换设备在统计页选择该 JSON、检查摘要、确认导入。

## 数据与奖励稳定性

- v2 使用 `localStorage['yike-study-v2']`；首次升级自动读取原来的 `yike-pomodoro-v1`，保留任务、历史专注次数和正在进行的计时，**不删除旧 key、不追发历史宠物奖励**。
- 升级前已经另存项目 ZIP；旧导出 JSON（无 v2 字段）不能直接导入 v2 的备份入口，原浏览器中的旧数据会自动迁移。
- 状态和奖励账本保存为一个 JSON，一次专注对应固定 session id；结算与发奖在同一次保存中完成。重复结算同一 id 不发奖。
- 支持 Web Locks 的浏览器使用同源锁串行化多个标签页操作，并监听 storage 事件同步。当前 Safari/Chrome 的 HTTPS 网站支持此 API；不支持时界面提示仅打开一个页面，回退模式不保证跨标签并发安全。
- 存储被禁用时提示内存模式；空间满导致写入失败时不提交该操作。数据格式损坏时暂停写入，保留原始文本供导出，并允许导入有效备份恢复。
- 本地数据不上传服务器，不跨设备自动同步。不同域名、端口或浏览器的存储彼此独立；清除网站数据会丢失记录。Safari 可能回收长期未使用的网站数据，请定期备份。
- 这是本地养成工具，去重用于防止正常操作中的误发，不是防篡改或跨设备的服务器结算系统。手工改 JSON、改系统时间或恢复旧备份不属于防作弊保障。

## iPhone Safari 限制

- 发音必须主动点击；可用音色、离线可用性、音量和声音输出由系统决定。无需麦克风权限，没有录音。
- 切到后台或锁屏后网页执行可能停止，本版不提供可靠后台响铃、通知或自动循环专注。
- 支持安全区域和手机竖屏。Safari 分享 → 添加到主屏幕可独立启动，但本版没有 Service Worker，不保证离线重新打开。
- 正式发布使用 HTTPS；局域网 HTTP 下部分浏览器可能缺少 Web Locks。建议同一时间只保留一个学习页面。

## 更换宠物的扩展方式

`pets.js` 的 `PET_CATALOG` 保存受信任的 SVG 模板与名称/类型，养成进度只保存 `pet.species` 与数值。添加新的 `{id, name, type, svg}` 条目后，“更换伙伴”选择框自动出现；更换只影响外观，保留经验、金币、学习记录和装饰。SVG 可复用 `.pet-head`、`.pet-eyes`、`.pet-tail` 等动作类。当前仅内置泰迪，没有展示不可用的其他宠物。未知类型的备份会先用泰迪显示并保留类型 id。未包含 species 的早期 v2 数据会自动补为 teddy，无需清除数据。

宠物外观来自项目内固定注册表；导入的 JSON 不能注入 SVG。
