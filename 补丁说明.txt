六级喵补丁包 v2（只含 2 个文件，覆盖同名文件即可）
用途：给阅读页加上「导入真题题型包」功能，这样选词填空 / 长篇匹配的真题包才能导进去。

上传方法（和上次一样）：
1. 打开仓库 chinese-pomodoro → Add file → Upload files
2. 把本包里的 index.html 和 v45-types.js 两个文件拖进去（会覆盖旧版）
3. Commit changes

传完后：
- 打开网站（带 ?v=46 的链接强刷一次），进阅读页，拉到最下面有「导入真题题型包（选词填空 / 长篇匹配）」卡片
- 选 types-2025-12-1.json 导入一次，再选 types-2026-06-1.json 导入一次
- 每套会出现两张卡：选词填空 + 长篇匹配，可直接做题判分
